# MitoForge

MitoForge is a personal fitness tracker that runs in the browser. Workouts, body logs, and settings stay on your device in `localStorage`. An optional AI coach can call Anthropic, xAI, or OpenAI with a key you type in; nothing is sent anywhere until you do that.

This repository is the installable app published with GitHub Pages.

## Open it

https://teripi71-lang.github.io/Mitoforge/

In the repo settings, set Pages to deploy from the `main` branch and the `/` (root) folder. The site is a project page, so it is served under `/Mitoforge/`, including the capital M.

## Install on a phone

The first visit needs a network connection. After that, the home-screen icon opens full screen and works offline. AI coach calls still need a connection.

### Android (Chrome)

1. Open the site in Chrome.
2. Tap the menu (⋮) and choose **Install app** or **Add to Home screen**.
3. Confirm. MitoForge is added to your home screen and opens without the browser toolbar.

### iPhone (Safari)

1. Open the site in Safari.
2. Tap the Share button, then **Add to Home Screen**.
3. Keep the name MitoForge and tap Add.

Installing does not move or clear your logs. They stay in this site's storage on this phone, under the same keys as before.
